User guide
==========

This guide is the practical half of the manual.  It goes through a calculation
in the order you would build one: make or read a mesh, describe the problem on
it, solve, and get the answers out.  Every keyword is explained where it first
appears, and every example is code that runs.

The other half is the :doc:`/theory/index`, which says what the code computes
and why, and :doc:`/objects`, which has one page per kernel, boundary condition
and material giving its parameters in full.
